# Athena Cloud Vision (Future)

> **Status:** Specification only — not implemented

## Goals

- Managed Athena runtime (athena-cloud)
- Hosted event bus, data lake connectors, and observability
- Multi-tenant bounded contexts with manifest-driven deployment

## Non-goals (MVP)

- No cloud implementation in monorepo MVP
- `athena-platform` remains the on-prem assembly target
